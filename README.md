# Uzaktan Kumanda Kaybolma Bakanlığı

**T.C. Ev İçi Kayıp Nesneler Genel Müdürlüğü**  
*Kuruluş tarihi: 9 Eylül 2026 — resmiyet derecesi: aşırı*

Bu yazılım, koltuğun altına, battaniyenin kıvrımına veya "az önce buradaydı" bölgesine düşen uzaktan kumandaları **bulmaz**.  
Bunun yerine kaybı evrakla belgeler, tebligat üretir, tanık ifadesi alır ve resmi bir kapanış tutanağı basar.

Kumanda bulunursa sistem çöker. Bu bir özelliktir.

## Kurulum

```bash
python3 main.py
```

Bağımlılık yoktur. Python 3 yeter. Çay tavsiye edilir ama zorunlu değildir.

## Kullanım

Program sorar:
- Kumanda kime ait?
- En son nerede görüldü?
- Şüpheli (kedi / misafir / yerçekimi) kim?

Sonra üç nüsha tutanak basar. Dördüncü nüsha evrenin arşivine gider; geri gelmez.

## Bilimsel dayanak

Yok.  
Ama yokluğu resmi bir yokluktur.

## Sık sorulan sorular

**Kumanda bulundu, ne yapayım?**  
Programı kapat. Bakanlık bu durumu tanımaz.

**Neden Türkçe?**  
Çünkü kayıp kumanda evrenseldir ama feryat yerlidir.

**Patates var mı?**  
Yok. Yasaktır.
